# YayoSystem para Foundry VTT (no oficial)

Sistema no oficial para jugar con las reglas de YayoSystem en Foundry VTT.

Requiere el manual original de IMSERSO to the limit. Este paquete no está afiliado, aprobado ni publicado por los autores o titulares de IMSERSO to the limit.

## Contenido

- Hojas de jubilado y extra.
- Tiradas de habilidad, Jamacuco, Salud, Yayopoints, iniciativa y combate.
- Arquetipos como objetos aplicables.
- Creador guiado de personajes según creación libre o por arquetipo.
- Compendios de reglas, ayudas, arquetipos y achaques.
